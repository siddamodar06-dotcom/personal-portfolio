# Personal Portfolio Website — HTML + CSS only

This version uses **no JavaScript**.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. You can use the Live Server extension, but it is optional.

## Edit before submission
Replace `Your Name`, college/school names, years, email, GitHub and LinkedIn links with your real details. Replace the sample project and achievement descriptions with your own work. Update the skill percentages honestly.

## Files
- `index.html` — all page sections and content
- `style.css` — design, responsive layout, CSS-only dark mode

## How the no-JavaScript features work
- Navigation uses normal HTML anchor links and CSS smooth scrolling.
- Dark/light mode uses a CSS checkbox and label.
- Contact form uses built-in HTML validation (`required`, `type="email"`, `minlength`).
- Skill bars are styled with CSS.

## Important limitations
- The contact form cannot send messages without a backend or form service.
- The CSS-only theme choice does not persist after reloading the page.
- The portfolio does not use JavaScript at all.
